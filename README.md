# shotlist.video

Marketing site for [shotlist](https://github.com/tushgaurav/shotlist).

A screenplay editor and a shot list pinned to the same scene. Rewrite the script and the plan stays put.

[shotlist.video](https://shotlist.video) · [the app](https://app.shotlist.io/)

```bash
npm install
npm run dev
```

[localhost:3000](http://localhost:3000)

Next.js, Tailwind, Motion, Lenis. Page sections are in `components/site`. Articles are in `lib/articles.ts`.
